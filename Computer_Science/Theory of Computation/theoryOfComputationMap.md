# Theory of Computation Map

## Topics/Skills

**Topics:** Computability, automata, sets, regular languages, and the pumping lemma

**Skills:** Read subset and proper-subset notation and use the pumping lemma to reason about whether a language is regular.

## Main Ideas

Computability theory studies which problems can be solved. Automata theory uses mathematical models to describe computation and the languages those models recognize.
