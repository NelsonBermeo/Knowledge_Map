# Security Map

## Topics/Skills

**Topics:** Confidentiality, integrity, availability, the McCumber Cube, security policies, memory safety, and system defenses

**Skills:** Describe security goals, distinguish policies from mechanisms, and identify protections for program memory.

## Main Ideas

Security policies define what should be allowed. Mechanisms enforce those policies, and assurance evaluates how much confidence to place in the design and implementation.

## Experience

The study notes cover security definitions, introduce memory safety, and describe operating system and compiler defenses. See the [experience file](experience.md) for details.
