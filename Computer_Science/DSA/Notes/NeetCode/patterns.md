#### 8 Patterns to solve 80% Leetcode Problems

Author: Sahil & Sarra
Link: https://www.youtube.com/watch?v=xo7XrRVxH8Y

1. Sliding Window

When we need to process a series of elements using a window. Usually utilize when a problem asks to find a subset of elements that satisfies a given condition

2. Subset

Used when we need to find all the possible combinations from a given set. Repititions may or may not be allowed based on the given problem. Take for example 46: Permutations from leetcode. We would need to create new subsets at every level which is similar to BFS.
