## Topics/Skills

**Topics:** Binary trees, binary search trees, subtree ordering, and search

**Skills:** Recognize the ordering rule in a binary search tree and use it to decide which subtree to search.

## Main Ideas

Data structures organize information for operations such as search. A binary search tree uses the ordering of keys to determine which branch can contain a target.
