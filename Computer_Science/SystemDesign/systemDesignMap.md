# System Design Map

## Topics/Skills

**Topics:** CPU, RAM, storage, cache, client–server architecture, persistence, vertical and horizontal scaling, and load balancing

**Skills:** Trace a request through a web application and explain the difference between vertical and horizontal scaling.

## Main Ideas

The notes start with the components of a single computer and build up to a web application with servers, persistent storage, and external APIs. Scaling changes either the capacity of each server or the number of servers handling requests.

## Experience

The architecture notes connect hardware fundamentals to the user and developer perspectives of a web application. See the [experience file](experience.md) for details.
