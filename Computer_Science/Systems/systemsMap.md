# Systems Map

## Topics/Skills

**Topics:** C compilation, ELF, program memory, stack frames, registers, assembly instructions, and the stack

**Skills:** Trace how a C program becomes an executable and read stack-frame diagrams and assembly examples.

## Main Ideas

The notes follow C source through compilation to execution. The executable format, memory layout, and stack diagrams show how function calls and program state are represented at runtime.

## Experience

The recaps include diagrams and worked examples for stack frames and assembly as background for the security notes. See the [experience file](experience.md) for details.
