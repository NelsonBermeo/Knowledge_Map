# AI Engineering Map

## Topics/Skills

**Topics:** Harness engineering, tools and context, Claude Agent SDK, model selection, smart routing

**Skills:** Use Claude from the terminal and programmatically, and compare models by capability, latency, and cost.

## Main Ideas

A model harness supplies the tools, context, and control flow around a model. Model selection balances the needs of each task against the speed and cost of the available models.
