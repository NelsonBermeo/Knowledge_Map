# Object-Oriented Programming Map

## Topics/Skills

**Topics:** Classes, objects, encapsulation, abstraction, inheritance, and polymorphism

**Skills:** Read Python examples of object-oriented design and relate those concepts to a Java application.

## Main Ideas

Object-oriented programs group state and behavior into objects. Encapsulation and abstraction define how other code uses those objects, while inheritance and polymorphism let related objects share interfaces and vary their behavior.
